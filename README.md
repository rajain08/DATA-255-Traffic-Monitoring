# UA-DETRAC Data Preparation

Data Pre-processing:

1. Run first 3 cells of UA_DETRAC_Data_Preparation_Student_Style.ipynb to download libraries and create directories
2. Download DETRAC-images.zip into folder data/zip manually from link: https://drive.google.com/file/d/1fQC6CEWOeL9pnJ4ZdD7U2gromcnWDRgm/view
3. Download DETRAC-Test-Annotations-XML.zip and DETRAC-Train-Annotations-XML.zip into folder data/zip manually from link: https://drive.google.com/drive/folders/1am_x3ywLJnABq4REtzbi0XTu5csFrp8v
4. Step 3 of the notebook will extract the zip files
5. Run the rest of the notebook for pre-processing to get started on YOLO
